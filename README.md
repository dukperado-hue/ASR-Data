# ASR Dashboard 2021–2025

แดชบอร์ดสรุปข้อมูลความปลอดภัยการบินของไทย (ตัวเลขรวมจาก ECCAIRS ไม่มีข้อมูลผู้รายงาน)
พร้อมแท็บ **GNSS รบกวน** แสดงการปลอมสัญญาณ (spoofing) และการรบกวน (jamming) GPS บริเวณไทย–เมียนมา

- ดูออนไลน์: https://dukperado-hue.github.io/ASR-Data/
- ข้อมูล GNSS: GPSwise public API (SkAI Data Services) จากข้อมูล ADS-B ของ OpenSky Network แสดงเฉพาะตัวเลขรวม
- ไลบรารี: Apache ECharts, MapLibre GL · แผนที่ฐาน: Esri, MapLibre demo tiles
